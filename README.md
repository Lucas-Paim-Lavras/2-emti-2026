# 📚 Repositório de Atividades e Exercícios — 2º Ano EMTI

Bem-vindos ao repositório oficial da turma do **2º Ano do Ensino Médio Técnico Integral (EMTI)**! 

Este repositório foi criado para servir como ponto central de envio, acompanhamento e avaliação de todas as atividades, projetos e exercícios práticos desenvolvidos ao longo do ano letivo.

---

## 🎯 Objetivo

O objetivo deste repositório é aplicar na prática os conceitos aprendidos em sala de aula, familiarizar os estudantes com ferramentas reais de mercado e controle de versão (**Git** e **GitHub**), além de compor as notas das avaliações do curso.

---

## 📂 Como Estruturar Suas Entregas

Cada estudante (ou grupo, quando indicado) deve organizar suas entregas seguindo o padrão de pastas e nomenclatura abaixo:

1. **Localização da Pasta:** As entregas devem ser feitas dentro da diretoria referente ao módulo/exercício atual.
2. **Nome da Pasta do Aluno:** Utilize o formato `NomeCompleto-Turma` (exemplo: `AnaSilva-2A`).
3. **Arquivo de Identificação:** Todo envio deve conter um arquivo `README.md` individual dentro da sua pasta com:
   - Nome completo do estudante
   - Turma e número de chamada
   - Breve explicação da solução desenvolvida
   - Instruções de como executar o código/projeto (quando aplicável)

---

## 🚀 Passo a Passo para Envio (Workflow)

1. Faça um **Fork** deste repositório para o seu perfil.
2. Clone o repositório forcado para a sua máquina local:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```
3. Crie uma branch para a atividade da semana:
   ```bash
   git checkout -b atividade-XX-SeuNome
   ```
4. Adicione os seus arquivos e faça os commits com mensagens claras:
   ```bash
   git add .
   git commit -m "feat: entrega da atividade XX - Seu Nome"
   ```
5. Envie para o seu repositório no GitHub:
   ```bash
   git push origin atividade-XX-SeuNome
   ```
6. Abra um **Pull Request (PR)** para a branch principal deste repositório com o título: `Entrega Atividade XX - Nome do Aluno`.

---

## 📊 Critérios de Avaliação

As atividades valem nota e serão corrigidas levando em consideração os seguintes pontos:

- **Pontualidade:** Respeito aos prazos definidos na descrição de cada atividade.
- **Corretude:** Atendimento a todos os requisitos solicitados na questão/projeto.
- **Boas Práticas de Código:** Organização do código, identação e boas mensagens de commit.
- **Documentação:** Presença de instruções claras no arquivo README da sua pasta.

---

## ⚠️ Avisos Importantes

- **Prazos:** Pull Requests abertos após a data/horário limite sofrerão desconto na nota ou poderão ser desconsiderados.
- **Autoria:** O objetivo das atividades é o aprendizado individual ou em equipe. Cópias não autorizadas entre alunos resultarão em anulação da nota para ambos.
- **Dúvidas:** Utilize a aba **Issues** deste repositório para tirar dúvidas sobre os exercícios com o professor ou colegas.
